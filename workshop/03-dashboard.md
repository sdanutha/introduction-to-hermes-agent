# 3. Dashboard

## Description

Dashboard is a web page for checking sessions, settings, profiles, and system status. It is good for management.

## Goal

Open Dashboard and find a Desktop session.

## Setup

Run `hermes dashboard` and open the Dashboard.

## Try it

| Step | Do this | Good result |
| --- | --- | --- |
| 1 | Run `hermes dashboard` | The Dashboard opens. |
| 2 | Open Sessions | The Desktop chat is visible. |
| 3 | Check the session details | The model and messages are clear. |

## Check the result

- The session shows the correct model and messages.
- The Desktop chat is visible in Dashboard.

## Safety

- Keep Dashboard local unless you configure secure access.

## Finish check

- The learner can open Dashboard.
- The learner can find a session.
- The learner understands that Desktop and Dashboard share sessions.
