# 3. Command Reference

Use Desktop and Dashboard first. Use these commands when needed.

## Start Hermes

```powershell
hermes desktop
hermes dashboard
```

## Check setup

```powershell
hermes doctor
hermes model
hermes tools
```

## Continue work

```powershell
hermes --continue
hermes sessions list
```

## Skills

```powershell
hermes skills browse
hermes skills search research
```

## Profiles and automation

```powershell
hermes profile list
hermes cron list
```

## If something fails

```powershell
hermes doctor
hermes model
hermes tools
```
