# 1. Start with Hermes Desktop

## Goal

Open Hermes Desktop, set up one model, and start one useful chat.

## Before class

Install Hermes Desktop for Windows:

- https://hermes-agent.nousresearch.com/docs/getting-started/installation

Open Hermes Desktop and complete the first setup.

If you use Nous Portal, choose the quick setup option.

## Prompt 1: Interview me

```text
I want you to interview me.

Ask one question at a time.
Wait for my answer before the next question.

Learn about:
- My work
- My regular tasks
- My goals
- How I create content or do research
- How I make decisions
- The apps and websites I use
- Tasks that take too much time
- Tasks I avoid or want help with

When we finish:
1. Summarize what you learned.
2. Suggest useful information to save in memory.
3. Ask for my approval.
4. Save only stable and useful information.
5. Do not save passwords, API keys, or secrets.
```

## Try a simple chat

```text
Look at this project.
Tell me:
1. What files are here?
2. What is the main file?
3. What should I check first?
```

## Explore Desktop

- Chat
- Projects
- File Browser
- Terminal
- Artifacts
- Settings

## Finish check

- Hermes Desktop opens.
- A model answers.
- The interview prompt works.
- The learner can find a project and a file.
